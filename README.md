PROJECT: DELIVERY SERVICE MANAGEMENT SYSTEM


* The objective of this project is to develop a database-driven system that supports the
management of delivery services, including customer orders, delivery assignments, vehi
cle tracking, and expense management, in order to enhance operational efficiency and
transparency.

* Technologies used: MySQL, Python, mysql-connector-python

* How to set up:
   1- Download dataset "import_data"
   2- Run create SQL scripts in "db"
   3- Import dataset into each table using MySQL Import Wizard
   4- Queries can now be tested
   5- Run Python application:
     - Install mysql-connector-python
     - Enter MySQL server password in "db_connection.py"
     - Run "main.py" on terminal: py main.py

  * "first_data" serves the only purpose of showing how I extracted the working dataset from the original one
